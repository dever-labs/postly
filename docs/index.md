# Postly

A cross-platform desktop API client built for teams — with native Backstage,
GitHub and GitLab integration. Built with Electron for Windows, macOS and
Linux.

Connect Postly to your Backstage instance or a git repository, and your APIs
appear as collections next to the ones you create locally. Requests support
REST, GraphQL, gRPC, WebSocket and MQTT, with auth configured once per
collection or group and inherited by its requests.

## Install

macOS, via [Homebrew](https://brew.sh):

```bash
brew install dever-labs/tap/postly
```

Windows and Linux: download the installer for your platform (`.exe`,
`.AppImage` or `.deb`) from the
[latest release](https://github.com/dever-labs/postly/releases/latest).
